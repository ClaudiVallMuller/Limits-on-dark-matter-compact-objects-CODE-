Code and lens models used for the numerical results of the article 'Limits on Dark Matter Compact Objects implied by Supermagnified Stars in Lensing Clusters' (Claudi Vall Müller & Jordi Miralda-Escudé, 2024).

'Lens models' contains the lens models used for each galaxy cluster.
'Figures'and 'Numerical results' contain the outputs of the paper. Both outputs can be reproduced using the following Python Notebooks:

'Table 1 Lensing parameters.ipynb' computes the lensing parameters from the lens models to generate Table 1 (results are already available in 'Numerical Results')
'Figure 1 Separations plot.ipynb' generates the Figure 1 of the paper.
'Figure 2 Likelihood function.ipynb' generates the Figure 2 of the paper.
Each python code works independently of the others.
